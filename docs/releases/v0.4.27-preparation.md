# BaseHarbor Console and v0.4.27

Console complements BaseHarbor's CLI with a browser-based view of applications, Targets, providers and operations. Core continues to own authorization, provider placement and deployment state; the Console does not independently manage runtime hosts.

The developer workstation connects to the management Core through the protected management boundary. Node Connector enrollment remains a separate operation for remote runtime hosts.

See the [Console overview](../../README.md), [integration records](../RELEASE-INTEGRATION.md) and [BaseHarbor v0.4.27 release notes](https://github.com/mcpdev80/baseharbor/blob/develop/docs/releases/v0.4.27.md).
